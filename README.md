# Sentiment Analysis Web App 🎭

This is a Tier-3 project for the Devotics Industrial Experience Program. It is a real-time web application built with Streamlit and TextBlob that analyzes the sentiment of user-provided text to determine if it is Positive, Negative, or Neutral.

## Features
- Real-time sentiment prediction using TextBlob's NLP polarity scoring.
- Modern, responsive web UI built with Streamlit and custom CSS (Dark Gradient Theme).
- Interactive text input and clear visual feedback for the user.

## Requirements
- Python 3.x
- Streamlit
- TextBlob
